## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Memory error** | Use Polars streaming |
| **Slow join** | Optimize with DuckDB |
| **Wrong types** | Force dtype on load |
| **Duplicate rows** | Dedupe by key |
| **API rate limit** | Add backoff |
| **Schedule fails** | Check permissions |
